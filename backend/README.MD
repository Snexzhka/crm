## CRM-система для управления клиентами и продажами
### Краткое описание

##### Корпоративная CRM-система, автоматизирующая процессы привлечения лидов, заключения контрактов, управления рекламными кампаниями и учёта активных клиентов. Реализована многоролевая модель доступа с разграничением прав через группы. Включает личный кабинет, дашборд со статистикой, систему напоминаний и ежедневник задач.
### Ключевой функционал

    * Управление услугами (продуктами) – создание, редактирование, просмотр.

    * Рекламные кампании – фиксация бюджета, привязка к услугам, статистика по лидам и клиентам.

    * Лиды (потенциальные клиенты) – сбор контактов, связь с рекламной кампанией, перевод в активные клиенты.

    * Контракты – регистрация договоров, длительность, стоимость, привязка к лиду и услуге.

    * Активные клиенты – создаются из лидов после заключения контракта, хранят историю сотрудничества.

    * Статистика рекламных кампаний – количество привлечённых лидов, активных клиентов, соотношение контрактов к бюджету.

    * Роли и разрешения (Django Groups):

        - Администратор – полный доступ, управление пользователями, правами.

        - Маркетолог – управление услугами и рекламными кампаниями.

        - Менеджер – управление лидами, контрактами, перевод в активных клиентов.

        - Оператор – только работа с лидами.

    * Личный ежедневник (задачи) – создание, отметка выполнения, автоматический перенос невыполненных задач на следующий день.

    * Дашборд – общая статистика (количество услуг, кампаний, лидов, клиентов) и мини-отчёты.


### Технологический стек

    * Бэкенд: Django 5.0 + PostgreSQL + SQLAlchemy (для тестирования)

    * Фронтенд: HTML5, Bootstrap 5, FontAwesome, собственный CSS

    * Тестирование: pytest + unittest (покрытие критических модулей)

    * Инструменты качества: pylint, mypy, black, isort


### Особенности реализации

    * Вычисление непрерывных серий (streak) для задач и привычек.

    * Автоматическое создание тестовой базы данных при запуске тестов (pytest-django).

    * Кастомные шаблоны с адаптивной вёрсткой.

#### Результат

##### Готовая к использованию CRM с удобным веб-интерфейсом. Позволяет бизнесу эффективно управлять воронкой продаж, отслеживать эффективность рекламы и автоматизировать рутинные задачи сотрудников.
